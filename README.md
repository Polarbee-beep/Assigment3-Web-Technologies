# Minecraft Building Commissions Website

### Project Topic
A multi-page responsive web platform built for an independent solo freelance Minecraft Builder operating under the brand **BlockCrafters**. It showcases unique build style advantages, clear transparent tier-based pricing metrics, a portfolio gallery, and provides a sleek functional contact form for prospective client commissions.

### Color Theme
**Purple Theme**: A cohesive design aesthetic utilizing a curated purple color palette inspired by the magical end-game elements of Minecraft (The End / Nether portals), pairing deep dark violets with rich glowing neon highlights.

### Requirements Fulfilled
1. **5 Connected Pages**: Home, About, Services/Pricing, Gallery, and Contact/Order pages seamlessly bound via a global navigation header.
2. **HTML5 Semantics**: Proper leverage of structural layout blocks (`<header>`, `<main>`, `<section>`, `<footer>`, etc.).
3. **Data Grid Table**: A beautiful, fully styled responsive pricing grid summarizing dimensions, times, and pricing.
4. **Input Form Validation**: Includes custom text inputs, selection dropdowns, and message blocks with specific focus pseudo-classes.
5. **Advanced CSS Positioning**: Implementation of structured CSS Grid layouts along with functional absolute text overlays aligned against a relative canvas context.
6. **Responsive Web Design Breakpoints**: Implemented custom media queries targeting distinct screen layouts (Tablets <= 992px, Mobile <= 576px) coupled with core Bootstrap alignment matrices.
